# Dra. Luiza Mei

Landing page da Dra. Luiza Mei Yeh, cirurgiã-dentista no Horto, em Belo Horizonte.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
```

O deploy para o GitHub Pages é executado automaticamente pela GitHub Actions a cada atualização da branch `main`.
